# Plan — v0.5.0 polish (design glow-up + bug fixes)

Spec: `docs/specs/2026-07-03-v0.5-polish.md`

## Order of work

Backend first (bugs are small and unblock QA), then frontend in component
order, then rebuild dist.

### Backend (worker)

1. **B1+B2 — validation guards.** `db.answerValidation` returns `null` for a
   missing row; server returns 404. If validation is not `pending`, server
   returns 409 `already answered`. TDD: extend `tests/api.test.mjs` with both
   cases first.
2. **B3 — dynamic health version.** `server.mjs` reads `version` from root
   `package.json` at startup (fs read, once). Test asserts it matches the
   package version. Bump root + plugin versions to 0.5.0 at the end.

### Frontend (dashboard)

3. **B4 — task sort fix** in `TaskBoard.jsx` (unknown status → last), part of
   the task-board rework.
4. **styles.css foundation** — tokens, panel hover lift, focus rings,
   scrollbar, shared animations (float, flicker, confetti keyframes),
   `prefers-reduced-motion` guard.
5. **CrewRoom** — perspective floor background, z-sort by y (`zIndex` from
   `pos.y`), depth scale, walking bob class while position transitions,
   station screen flicker.
6. **Timeline** — vertical rail with per-kind colored dots, relative
   timestamps (tick every 30s), phase events as separators.
7. **TaskBoard** — SVG progress ring, grouped status sections, fixed sort.
8. **DecisionsPanel** — extracted component, card styling, empty hint,
   always rendered.
9. **ValidationPanel** — gate icons, last-answered strip, button micro-press.
10. **Empty hero + App shell** — starfield drift, floating title, topbar
    phase pill.
11. **Celebrations** — `useCelebration` hook watching snapshot transitions
    (validation → approved, phase → done); DOM confetti burst, no deps.

### Ship

12. **QA:** full `node --test tests/*.test.mjs`; dashboard `npm run build`;
    verify live at :4519 (serve check via curl + manual look).
13. Security + review passes per workflow; version bump to 0.5.0.
