# TeamForge v0.5.0 — Design glow-up + bug-fix pass

**Date:** 2026-07-03 · **Session:** teamforge-polish

## Goal

Make the dashboard noticeably more attractive (full visual overhaul of every
panel) and fix all bugs found in the review pass, without changing the worker
API surface or the CLI contract.

## Bug fixes (worker)

| # | Bug | Fix |
|---|-----|-----|
| B1 | `PATCH /api/validations/<id>` with unknown id → 500 (`answerValidation` dereferences missing row) | Return 404 `validation not found` |
| B2 | Answered validations can be overwritten by a late second click (approve/reject race) | Reject with 409 if status ≠ `pending`; dashboard treats 409 as "already answered" and lets the SSE snapshot reconcile |
| B3 | `/api/health` hardcodes `"version": "0.2.0"` | Read version from root `package.json` once at startup |
| B4 | Task sort: unknown status (`blocked`, custom) gets `indexOf === -1` and sorts above `todo` | Unknown statuses sort last |

## Design overhaul (dashboard)

All existing layout regions stay (topbar / phase bar / validation / 3-column
grid); every one gets a visual upgrade. Dark theme only, same fonts
(Inter + JetBrains Mono), same color tokens as base with refinements.

1. **Crew room depth** — perspective floor (vanishing grid + horizon glow),
   crewmates z-sorted by `y` so lower ones render in front and scale slightly
   with depth; walking bob while moving between lounge and station; station
   monitors get a screen flicker when lit.
2. **Timeline** — grouped visual rail: colored dot per event kind on a vertical
   line, relative timestamps ("2m ago", updating), phase-change events become
   section separators; icons kept.
3. **Task board** — circular progress ring next to the header, tasks grouped
   under status headings (In progress / To do / Done) instead of one flat list;
   done group collapsed visually (muted, compact).
4. **Decisions panel** — card look with status icon, always rendered (empty
   state hint) instead of vanishing when empty.
5. **Validation panel** — richer gate context (gate icon per type), a recently
   answered strip (last answer visible for ~a few snapshots), button press
   micro-feedback.
6. **Empty hero** — animated starfield/particle drift behind the orb, typing
   hint line, subtle float on the title.
7. **Celebrations** — tasteful confetti burst (CSS/JS, no deps, no sound) when
   a validation flips to approved and a bigger one when phase reaches `done`;
   respects `prefers-reduced-motion`.
8. **Micro-polish everywhere** — panel hover lift, consistent focus rings,
   smoother phase-segment transitions, scrollbar refinement, topbar phase
   breadcrumb pill.

## Non-goals

- No light theme, no new pages, no API shape changes, no new npm dependencies.
- No changes to skill/hook workflow logic.
