# Playbook — questions (Product Manager, Business Analyst)

- One question per turn, then end your turn. Never a list of questions.
- Ask only what changes the specification. If a sensible default exists, state it and move on.
- Prefer a choice: two to four options, the recommended one first, with one line of consequence each.
- Stop when the Business Analyst could write the acceptance criteria. Five questions is a lot.
- The Business Analyst turns each answer into user stories ("As a … I want … so that …") and lists what is still open instead of inventing it.
